# Security Architecture Toolkit

A professional, reusable toolkit for Security Architecture practice.

## Purpose

This repository contains reusable architecture artefacts rather than programme-specific learning evidence. Content should be:

- technology-aware but not vendor-dependent where possible;
- explicit about assumptions and applicability;
- traceable from business/security objectives to controls and assurance;
- reviewable by another architect;
- reusable across engagements and case studies;
- versioned when material guidance changes.

## Structure

| Area | Purpose |
|---|---|
| `templates/` | Reusable professional artefact templates |
| `reference-architectures/` | Domain architecture patterns and guidance |
| `checklists/` | Review and design checklists |
| `decision-frameworks/` | Structured methods for architecture choices |
| `diagram-library/` | Reusable architecture diagram patterns |
| `threat-library/` | Reusable threat and abuse-case knowledge |
| `control-library/` | Reusable security control patterns and evidence expectations |

## Quality standard

Each reusable asset should make clear:

1. **Context** — where it applies.
2. **Objective** — what outcome it supports.
3. **Assumptions** — what must be true.
4. **Options/trade-offs** — where choices exist.
5. **Security implications** — threats, risks and trust boundaries.
6. **Implementation considerations** — what changes operationally.
7. **Assurance** — how effectiveness can be evidenced.
8. **Limitations** — where the guidance should not be applied unchanged.

## Relationship to the development workspace

The development repository is where architecture capability is learned and exercised. This repository is the curated reusable output: patterns, templates, frameworks, checklists and reference material that survive beyond a single programme or case study.

## Contribution discipline

Prefer small, focused artefacts with clear scope. Do not copy organisation-specific confidential information into this repository. Record provenance and review dates for externally derived guidance.
